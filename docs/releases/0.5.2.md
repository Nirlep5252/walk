# Walk 0.5.2

- Adds Quicklinks with aliases and parameterized targets.
- Adds built-in quicklinks for Google, GitHub, YouTube, Maps, Wikipedia, and DuckDuckGo.
- Supports commands like `ql`, `ql add Name = https://example.com/{query}`, `ql remove name`, and direct aliases like `gh walk`.
- Adds a Settings toggle for Quicklinks.
