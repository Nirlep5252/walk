# Walk 0.5.3

- Adds Favorites and Pins for apps, run targets, files, quicklinks, clipboard items, currency conversions, and system commands.
- Adds `fav`, `favorite`, and `favorites` searches for pinned items.
- Adds `Ctrl+P` pin and unpin actions across supported result types.
- Supports manual favorite ordering with `Ctrl+Up` and `Ctrl+Down`.
- Refreshes visible launcher results immediately after pin, unpin, and reorder actions.
- Recalculates pinned currency conversions when favorites are shown or copied.
